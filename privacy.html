Privacy

Short version: neither this website nor the app collects anything about you, and the app never keeps or sends what you type.

The app

Keyboard Gobloon has to see your keystrokes to do its job. It keeps only the word you are typing, in memory, so it can retype it in another layout, and forgets it when the word ends. Nothing you type is written to disk, logged or sent anywhere. The log file next to the settings holds technical messages only, such as the app's version and errors.

It sends no usage data and has no account. In password fields and windows you exclude it will do nothing. Planned features that download something, such as language packs or the AI model, will ask first and download from GitHub.

This website

The site is a set of static pages hosted on GitHub Pages. It sets no cookies, runs no analytics and has no forms. GitHub may log visits as described in the GitHub privacy statement. Fonts load from Google Fonts and icons from unpkg, so those services see your IP address when the page loads.
