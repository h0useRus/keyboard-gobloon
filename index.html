Typed in the wrong layout?

Keyboard Gobloon retypes the last word in the layout you meant and switches the keyboard for you. A light, private replacement for the Windows language switcher.

You look up and half a sentence is gibberish

Everyone who types in two languages knows it: the layout was wrong, and the only fix is to delete, switch and type it all again.

Features

Small, fast and out of your way

Written in Rust. It waits for keys and does nothing else, so it costs less than the Windows switcher it replaces.

  • Retype the last word in the next layout
  • Press again to go back
  • Any layouts installed in Windows
  • Keeps capitals and the spaces you typed
  • A click or Enter starts a new word
  • Never logs or sends what you type
  • Starts with Windows, lives in the tray
  • Installs without administrator rights
  • Portable zip, nothing to install
  • About 2 MB of memory, no CPU at rest

How it works

Three steps, no settings

  1. Install

    Run the installer, no administrator rights needed, or unpack the portable zip anywhere. Keyboard Gobloon starts in the tray.

  2. Type as usual

    It remembers only the word you are typing, as keys, so it can show that word in any layout.

  3. Press Pause

    When a word comes out in the wrong layout, press Pause. The word is retyped and the layout switched; press it again to go back.

FAQ

Questions before you try it

Is Keyboard Gobloon free?

Yes. It is open source under the MIT license. There is no account, no trial and nothing to buy.

Does it send or store what I type?

No. It keeps only the word you are typing in memory, so it can retype it, writes nothing you type to disk and sends nothing anywhere. The source code is open to check.

Which languages does it support?

Fixing the last word works between any keyboard layouts installed in Windows. Automatic switching and typo correction will start with English and Russian, with more languages as downloads.

My keyboard has no Pause key. What now?

On many laptops it is Fn plus another key. Choosing your own key is the next thing on the roadmap.

Why does it not work in some windows?

Windows does not let a normal program type into windows that run as administrator. An option to run Keyboard Gobloon as administrator is planned.

Why does Windows SmartScreen warn on the first start?

Builds are not code-signed yet, and new releases need some downloads before SmartScreen trusts them. Choose More info, then Run anyway.

Is it ready for daily use?

It is in early alpha: fixing the last word works, the rest is on the roadmap. Bugs reported on GitHub get fixed quickly.
